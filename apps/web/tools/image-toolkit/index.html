画像を、軽く整える。

選んだ画像はブラウザ内で処理します。リサイズ、形式変換、品質調整を行い、Canvasから再書き出しすることで画像メタデータも取り除きます。

ローカル処理 画像はこの端末のブラウザ内だけで処理され、どこにも送信されません。
