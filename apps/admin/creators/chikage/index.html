TRPG / SCHEDULER

Scheduler

スケジューラはSupabase上のライブデータを扱うため、静的CMSへ複製せず同じ正本を操作します。

LIVE DATA

卓スケジューラ

作成、回答、集計、確定、共有は既存のSchedulerをそのまま正本として使います。

Schedulerを開く ↗データ接続を確認

TRPG / CALENDAR

Calendar

Schedulerで確定したセッションを同じデータから表示します。二重入力はしません。

SYNCED

Session Calendar

確定結果の確認と公開表示はCalendarへ。編集元はSchedulerの確定データです。

Calendarを開く ↗Schedulerへ

MANAGE / NAVIGATION

Navigation

Creator Site内の順番、表示名、表示/非表示。URLはページIDから安全に固定されます。

MANAGE / DESIGN

Design / World

Creatorごとの世界観。アクセントは共有しますが、可読性の基礎色と状態色はAdmin側で保護します。

Adminでは本文・フォーム・Success / Warning / Danger色をテーマ色だけで上書きしません。見やすさを優先した上で千景の紫をアクセントとして使います。

MANAGE / INTEGRATIONS

MANAGE / PUBLISH

Publish

千景に属する変更を確認してPublic Snapshot / Build契約へ渡します。RELMUA全体の公開管理とは階層を分けます。
