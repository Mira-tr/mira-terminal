# RELMUA v2 Image Brief

RELMUA v2 の実装は、以下の画像が未配置でもグラデーションで成立するように作られています。Work ではこの文書を正本として画像だけを制作し、指定パスへ配置してください。

## 共通ルール

- 画像内に文字・ロゴ・UIラベルを描かない。文字はHTML/CSS側で重ねる。
- 透かし、署名、疑似ブランドロゴを入れない。
- いわゆる「AIイラスト感」の強い過剰な発光、無意味な粒子、極端な被写界深度、破綻した小物を避ける。
- RELMUAの基調は、アイボリー、深い緑、墨色、少量の暖色。派手なネオン主体にしない。
- 写真そのものより、質感のあるエディトリアルイラスト / コンセプトアート寄り。画面全体を情報で埋めない。
- PCでは大胆にトリミングされ、スマホでは中央寄りに切り抜かれる。主要被写体は中央60%へ収める。
- 出力は WebP。可能なら元画像も保持するが、Public配置はWebPのみ。

## 01. Home Hero

**配置先:** `apps/web/assets/editorial/relmua-v2-hero.webp`

**推奨:** 2400 x 1600 / 3:2

RELMUA全体を象徴するメインビジュアル。ゲーム、コード、設計図、AI、制作机を直接アイコンのように並べず、「何かを組み立てて世界へ変えていく工房 / 記録室」の空気を一枚で表す。静かだが密度があり、初見でブランドサイトらしい格を出す。人物は必須ではない。

## 02. element

**配置先:** `apps/web/assets/editorial/relmua-v2-element.webp`

**推奨:** 1800 x 1200 / 3:2

元素変換で状態を変えながら進む探索アクションのコンセプト。荒廃した施設、停止した機械、熱・水・電気などの変化を一つの景色で感じられるもの。ゲーム画面のスクリーンショット風にはしない。HUDなし。

## 03. NIIA / Home & Projects

**配置先:** `apps/web/assets/editorial/relmua-v2-niia.webp`

**推奨:** 1800 x 1200 / 3:2

RELMUA Projectとしての「にーあ」。既存のにーあシリーズの正式デザインを使い、かわいさだけではなく「人格を持つAIプロジェクト」の静かな存在感を出す。Discord Bot専用の絵にしない。スマホ、PC、チャット吹き出しなどのUIを大量に置かない。

## 04. Tools

**配置先:** `apps/web/assets/editorial/relmua-v2-tools.webp`

**推奨:** 1600 x 1100

制作道具の抽象ビジュアル。画像編集、変換、整理を連想できる構成だが、実在アプリのUIスクリーンショットにはしない。紙、フレーム、グリッド、トリミング、素材整理などの視覚言語を使う。

## 05. Notes

**配置先:** `apps/web/assets/editorial/relmua-v2-notes.webp`

**推奨:** 1800 x 1200 / 3:2

制作記録を象徴する机 / ノート / ラフ / 図面。整いすぎたモデルルームより、実際に考えている途中の痕跡がある。読める文章は画像に描かない。

## 06. Creator Chikage

**配置先:** `apps/web/assets/editorial/relmua-v2-chikage.webp`

**推奨:** 1600 x 1800 / 8:9

千景のCreator入口用。既存の千景ビジュアルを正本にする。人物を使う場合は既存デザインの同一人物性を優先し、RELMUA全体の緑・墨・アイボリーへ馴染ませる。TRPG専用に見える小物へ寄せない。

## 07. NIIA Detail Hero

**配置先:** `apps/web/assets/editorial/niia-v2-hero.webp`

**推奨:** 2200 x 1500

NIIA詳細ページの主役画像。にーあを大きく見せる。単なるキャラクター紹介ではなく、「この存在の裏側にシステムがある」ことがうっすら感じられる構図。文字なし。

## 08. NIIA Forms

**配置先:** `apps/web/assets/editorial/niia-v2-forms.webp`

**推奨:** 2000 x 1400

同一人物の三形態「にーあ / ニーア / ニア」を一枚に収める。三人の別キャラクター集合絵に見せず、同じ存在の表れ方が変化したことが分かる統一感を最優先する。

- にーあ: 明るく好奇心が前に出る。
- ニーア: 少し落ち着き、包容力が強い。
- ニア: 静かで眠たげ。

## 配置後の確認

1. 各ファイル名が完全一致していること。
2. WebPであること。
3. 主要被写体が中央60%に収まっていること。
4. 画像内に読ませる文字がないこと。
5. `npm run check` と `npm run build:public` を実行すること。
6. Home / Projects / NIIA をPC幅とスマホ幅で確認し、顔や主要物がトリミングで欠ける場合は画像側を再調整すること。
