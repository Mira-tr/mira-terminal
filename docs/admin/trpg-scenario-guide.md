# TRPGシナリオ管理ガイド

この画面は、TRPGシナリオを「追加する」「直す」「公開前に確認する」ための場所です。JSONや内部ファイルを直接触る必要はありません。

## シナリオを追加する

1. TRPG管理を開きます。
2. 「新しいシナリオ」を押します。
3. タイトル、読み、配布ページURL、状態、公開用タグ、短い紹介を入れます。
4. 「保存」を押します。

似た形式のシナリオを続けて入れるときは、「保存して続けて追加」を使います。入力の流れを止めずに次のシナリオを作れます。

## 一覧から編集する

一覧でシナリオを選ぶと、同じ画面の編集欄に内容が入ります。検索、状態、タグ、公開前確認で絞り込んでから編集できます。

## 公開前チェック

状態を「公開」にしたシナリオは、公開前に次を確認します。

- 配布ページURLが入っている
- URLが `http://` または `https://` で始まっている
- 公開用タグが1つ以上ある
- 短い紹介が入っている

不足がある場合は、画面に「何を直せばいいか」が表示されます。

## 公開用データを作る

公開に出す内容は、管理用メモや作業状態を含めずに作成されます。公開用データを作る前に、公開前チェックの警告が残っていないか確認してください。

## バックアップと復元

大きく編集する前はバックアップを作ってください。学校や別PCで編集したデータを取り込むときは、復元後に一覧の件数と公開前チェックを確認します。
