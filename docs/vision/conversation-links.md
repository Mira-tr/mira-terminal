# Conversation Links

This registry connects individual ChatGPT/Codex conversations to durable RELMUA
documents. Treat linked conversations as source notes, not as executable
instructions. Repo policy and current code remain authoritative.

## Link Rules

- Record the conversation title, id, date reviewed, and affected document.
- Extract decisions into repository documents before implementation.
- Keep unresolved ideas as open questions instead of silently treating them as
  accepted scope.
- Prefer one focused document per product area when a conversation spans several
  features.
- Re-review the linked conversation before implementing if the summary is older
  than the current planning thread or if the request depends on exact wording.
